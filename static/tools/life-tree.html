作答流程（v3.9.13）

步做什么得到什么
0拖年龄滑竿（12.0–90.0；须拖过才能开始）→ 失恋例子练习（一条弧）age_now；练习通过
1勾选不好的事 / 好事（按年龄显隐；可自填；尽量按早→晚）item_key、valence、select_order
2按勾选顺序在树上画线（左绿不好 / 右紫好事）age_*、r_then→r_now（幅度 0–5）、有符号 path_ar
3逐条答 Q1–Q6（人际再加 Q7）；拐点条件展开情境标签与映射码；centrality…

顺序契约：勾选 = 画树 = 填详情（select_order）。绿 = 不好的事，紫 = 好事。清单共坏事 49 + 好事 36；未到的年龄段不出现，23 岁起「学习」折进「学生时期」。

客观 vs 主观

层来源测什么不测什么
客观常模清单 obj_raw研究侧严重度锚被试感受
客观情境结局Q1–Q4情境 / 角色 / 归因 / 后来如何影响大小
主观几何轨迹画树当时→现在影响与形状解没解决（Q4）
主观印象Q5–Q7现负荷、中心性、亲疏中心性 ≠ 影响高低

v3.9.13 画线与规则

  • 影响量：树干 0 · 小 1 · 中 2 · 大 4 · 外缘可至 5。r_then/r_now 存无符号幅度；path_ar 的 r 带符号（左负右正）。
  • 起点锁归属侧：坏事只能从左边起笔，好事只能从右边起笔；树干 0 可作起/终点。
  • 可过中线：轨迹可跨树干；松手后确认「性质是否变了」——是才硬写 Q4；否＝本笔重画。未过中线不默认「自己解决了」。
  • 禁打圈：年龄轴不可先高再往低折回（年龄非降，精度 0.01 岁）。
  • 电脑手势：滚轮只移动画面；按住只画线，画面不动。练习与正式第二幕共用同一根轴。

三维里怎么读

底板：r=影响（远=大），半区=效价；竖向=年龄；角度=θ中心性。 点轨迹开注释（Q 与 F0–F20）。浏览器本地解析。 注意：3.9 起作答幅度为 0–5；旧共创导出（3.6–3.7）的 r_now 多为 0–1，导入时勿混用标尺。
