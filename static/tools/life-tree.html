生命树影响轨迹

v3.5.0 · tool_version life-tree-3.5.0

可嵌问卷星的手机端测量：勾选正/负人生事件 → 在树上画出「当时→现在」的影响轨迹 → 短标签补情境与结局。 测的是影响如何随时间变化，不只「有没有发生过」。

作答流程

步做什么得到什么
1勾选不好的事 / 好事（可自填；尽量按早→晚）item_key、valence、select_order、预设 obj_raw
2按勾选顺序在树上画线（左绿不好 / 右紫好事）age_*、r_then→r_now、path_ar（有符号 r，≤32 点）
3逐条答 Q1–Q6（人际再加 Q7）；拐点条件展开where/who/why/how 与映射码；now_salience、centrality…

顺序契约：勾选顺序 = 画树顺序 = 填详情顺序（select_order）。绿 = 不好的事，紫 = 好事。

客观 vs 主观

层来源测什么不测什么
客观常模清单 obj_raw（不可见）研究侧严重度锚被试感受
客观情境结局Q1–Q4情境 / 角色 / 归因 / 后来如何影响大小、故事核心度
主观几何轨迹画树当时→现在影响与形状解没解决（那是 Q4）
主观印象Q5–Q7现负荷、中心性、亲疏中心性 ≠ 影响高低

v3.5 画线与 Q4

  • 起点锁归属侧：坏事只能从左边起笔，好事只能从右边起笔（标签是真归属）。
  • 可过中线：之后轨迹可跨树干（坏→好 / 好→坏）；path_ar 存有符号 r。
  • 过中线 → 硬写 Q4：负→正「后来变好了」；正→负「后来失去了」；并预填拐点岁。未过中线不默认「自己解决了」。
  • 禁打圈：年龄轴不可先高再往低折回（程序钳制）。

三维查看器读什么

底板极坐标：r = 影响（远+粗=大），θ = 中心性（故事核心度，不是影响高低）；竖向 = 年龄。 点轨迹可读 Q 与转换字段（F0–F20）。数据在浏览器本地解析，不上传服务器。

打开三维结果查看器 → 粘贴 / 导入 life_tree_payload_json 或 {"events":[…]}；含预试示例
