作答流程

步做什么得到什么
1勾选不好的事 / 好事（可自填；尽量按早→晚）item_key、valence、select_order
2按勾选顺序在树上画线（左绿不好 / 右紫好事）age_*、r_then→r_now、path_ar
3逐条答 Q1–Q6（人际再加 Q7）；拐点条件展开情境标签与映射码；centrality…

顺序契约：勾选 = 画树 = 填详情（select_order）。绿 = 不好的事，紫 = 好事。

客观 vs 主观

层来源测什么不测什么
客观常模清单 obj_raw研究侧严重度锚被试感受
客观情境结局Q1–Q4情境 / 角色 / 归因 / 后来如何影响大小
主观几何轨迹画树当时→现在影响与形状解没解决（Q4）
主观印象Q5–Q7现负荷、中心性、亲疏中心性 ≠ 影响高低

v3.5 画线与 Q4

  • 起点锁归属侧：坏事只能从左边起笔，好事只能从右边起笔。
  • 可过中线：轨迹可跨树干；path_ar 存有符号 r。
  • 过中线 → 硬写 Q4：负→正「后来变好了」；正→负「后来失去了」。未过中线不默认「自己解决了」。
  • 禁打圈：年龄轴不可先高再往低折回。

三维里怎么读

底板：r=影响（远=大），半区=效价；竖向=年龄；角度=θ中心性。 点轨迹开注释（Q 与 F0–F20）。浏览器本地解析。
